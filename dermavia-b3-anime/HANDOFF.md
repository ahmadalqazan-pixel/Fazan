# Dermavia · سيروم Azelaic & Salicylic B3 · إعلان أنمي 20 ث — تسليم لـ Claude Code

## الحالة
- الصورة كاملة: 9 لقطات، 1080×1920، 24fps، 20 ث بالضبط. `draft_silent.mp4` = النسخة الحالية بدون صوت.
- الباقي: تسجيل صوت أحمد (5 جمل)، موسيقى/مؤثرات اختيارية، الدمج، وتعديلات رسم إذا انطلبت.

## الملفات
| الملف | شنو هو |
|---|---|
| `index.html` | الفلم كامل وقائم بذاته (الخطوط وصورة العبوة مدمجة). افتحه بالمتصفح = معاينة تشتغل وتعيد |
| `render.mjs` | تصدير: Playwright يلقط كل فريم + ffmpeg → H.264 yuv420p |
| `sheet.md` | ترتيب اللقطات (shot sheet) والباليت |
| `source/film.js` | الكود القابل للتعديل (كل لقطة دالة `shotN(t)`)، يستورد `/core/lib.js` من مكتبة lemo-opuscar |
| `source/assets/serum_packshot.png` | صورة العبوة من البروشور بألوان الكتالوج |

## التشغيل
```bash
npm install && npm run setup     # playwright + chromium (يحتاج ffmpeg بالنظام)
npm run render                   # → out/dermavia-b3-anime.mp4
```
للتعديل: عدل `index.html` مباشرة (الكود داخل `<script type="module">`)، أو عدل `source/film.js` وأعد دمجه.

## الصوت (أحمد يسجل، كل جملة ملف)
| ملف | يبدي عند | الجملة |
|---|---|---|
| vo1 | 3.5 ث (لقطة 3) | فالحل: تشيل الميت… وتحمي الحي. |
| vo2 | 7.9 ث (بعد الاصطدام، لقطة 5) | أربعة بعبوة وحدة. |
| vo3 | 10.0 ث (لقطة 6) | مرة أو مرتين باليوم بعد الغسول، وواقي شمس بالنهار. |
| vo4 | 15.0 ث (لقطة 8) | ما تعرف إذا يناسبك؟ دز نوع بشرتك واتساب |
| vo5 | 17.5 ث (لقطة 9) | وصيدلاني يجاوبك مجاناً. |

**جاهز:** حط الملفات بـ `vo/vo1.wav … vo/vo5.wav` (أي صيغة) وشغّل `./mix.sh` أو `./mix.sh music.wav` → `final.mp4`. السكربت يسوي الخطوات الجاية تلقائياً.

دمج: ضع كل ملف بوقته (`adelay`)، صوت أعلى من الموسيقى بـ ~10 dB، طبّع لـ −14 LUFS، ثم
`ffmpeg -i out/dermavia-b3-anime.mp4 -i mix.wav -c:v copy -c:a aac -b:a 192k -shortest final.mp4`

## قواعد لازم تبقى
1. العبوة = صورة الكتالوج بدون أي تغيير بالألوان أو الإضاءة أو الشكل؛ بس الحجم والمكان.
2. الكلام والنصوص من الكتالوج فقط؛ ممنوع نسب مئوية مو موجودة بالكتالوج، وممنوع "علاج نهائي" أو "نتيجة مضمونة". ماكو لقطة قبل/بعد.
3. لهجة عراقية. النص العربي RTL و≤ 6 كلمات بكل كارت.
4. الألوان من الباليت بس: #0E1420 #D8A47F #2FA062 #212C51 #F7F5F0 #2A1E2E (ودرجاتها).
5. أسفل 20% من الشاشة فاضي للكابشن، والوجوه بالثلث العلوي.
6. الصيدلاني بلقطة 3 مرسوم على شكل أحمد؛ البطل شخصية أصلية. ماكو شعار واتساب.
7. لا تصرف رصيد Higgsfield بدون موافقة أحمد.
8. كل شي دالة من الوقت t (لا Math.random بدون seed، ولا requestAnimationFrame بوضع التصدير).
